# Generic RPG 3D (Godot 4)

Samostatný **skutečně 3D** prototyp inspirovaný původním Flutter/Bonfire projektem.

## Spuštění
1. Nainstaluj Godot 4.x.
2. Otevři Godot Project Manager -> Import a vyber `project.godot`.
3. Spusť projekt klávesou F6/F5.

## Ovládání
- WASD: pohyb
- Mezerník nebo levé tlačítko myši: útok na nepřátele v dosahu

## Funkce
- 3D scéna, nasvícení, kolize, kamera třetí osoby
- Pohyb hráče, zdraví a automatické znovuobjevení
- Démoni s pronásledováním, útokem, životy a respawnem
- Počítadlo poražených nepřátel

## Omezení
Jde o první prototyp, nikoli kompletní port původní hry. 3D modely jsou zatím jednoduché geometrické tvary. Chybí inventář, mobilní dotykové ovládání, animace a ukládání. Nebylo možné projekt spustit v Godotu v tomto prostředí.
