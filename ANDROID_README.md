# Android verze pro Samsung Galaxy S24+

Tato verze obsahuje dotykový joystick a tlačítko útoku. Jde o zdrojový projekt Godot 4, **nikoliv hotové APK**.

## Export APK
1. Nainstalujte Godot 4 a Android export templates.
2. Nainstalujte Android SDK a JDK podle oficiální dokumentace Godotu.
3. V Godotu otevřete `project.godot`, Project > Export > Add > Android.
4. Nastavte Android SDK/JDK v Editor Settings a podpisový klíč podle typu sestavení.
5. Exportujte APK a nainstalujte jej do telefonu.

Hra nebyla otestována v Godotu ani na telefonu. Cílové nastavení je režim na šířku a mobilní kompatibilní renderer.
